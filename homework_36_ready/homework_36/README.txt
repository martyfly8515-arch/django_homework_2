Домашнее задание №36
Модуль 19. Шаблоны: Расширенные инструменты

Реализовано:
- Navbar
- Accordion
- Footer
- Всплывающее сообщение Toast
- Modal
- Cards
- Carousel

Bootstrap подключён через CDN.

Как проверить:
1. Откройте терминал в папке homework_36.
2. Установите Django:
   pip install -r requirements.txt
3. Запустите:
   python manage.py runserver
4. Откройте:
   http://127.0.0.1:8000/

Как загрузить в GitHub:
1. Распаковать архив.
2. Папку homework_36 целиком загрузить в корень django_homework_2.
3. Старые задания не удалять.
