Домашнее задание №32
Модуль 17. Формы и наборы форм: расширенные инструменты

Что выполнено:
1. Создана обычная форма forms.Form, не связанная с моделью.
2. В контроллере данные проверяются через form.is_valid().
3. После проверки данные берутся из form.cleaned_data.
4. Результат вручную сохраняется в модель Feedback через Feedback.objects.create().
5. Подключена библиотека django-simple-captcha.
6. В форму добавлено поле CaptchaField.

Как проверить проект:

1. Откройте терминал в папке homework_32.
2. Установите зависимости:
   pip install -r requirements.txt

3. Выполните миграции:
   python manage.py migrate

4. Запустите сервер:
   python manage.py runserver

5. Откройте:
   http://127.0.0.1:8000/
