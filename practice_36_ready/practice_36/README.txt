Практическая работа №36
Модуль 19. Шаблоны: Расширенные инструменты

Выполнено:
1. Bootstrap подключён через CDN.
2. В views.py создан массив товаров.
3. Массив передаётся в шаблон Django.
4. Данные выводятся циклом {% for %}.
5. Для вывода используются Bootstrap Card.

Как проверить:
1. Откройте терминал в папке practice_36.
2. Установите Django:
   pip install -r requirements.txt
3. Запустите:
   python manage.py runserver
4. Откройте:
   http://127.0.0.1:8000/
